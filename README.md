# From Voice to Screen

An original interactive digital humanities portfolio for Anjali Anand's BA English CIA assignment at Christ University.

## Edit your portfolio

- `index.html` contains the structure and editable placeholder copy.
- `style.css` contains the responsive editorial visual system.
- `script.js` contains the text cards, annotation gallery, reflection chapters, modal cards and interactions.
- Add your own images under `images/annotations/` using the filenames shown in the annotation placeholders, or update the `data-image` values in `script.js`.
- Replace the photograph placeholder in `index.html` with an image when ready.
- Search for `[Add` and `[Write` to find content that is waiting for your personal details.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. The site uses only HTML, CSS and JavaScript, so no build step is needed.

The site deliberately leaves author details, responses, annotation scans and reflection prompts editable rather than fabricating academic material.
